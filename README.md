# Meu Financeiro

App de finanças pessoais (PWA) com Firebase Authentication e Firestore.
Funciona no iPhone, no Android e no computador: abra o link e adicione à tela inicial.

- `index.html`, `styles.css`, `app.js` — o aplicativo
- `firestore.rules` — regras do banco (cada usuário só acessa os próprios dados)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — instalação na tela inicial e uso offline
